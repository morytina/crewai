# CrewAI Project

This project was scaffolded to match the structure generated by:

```bash
crewai create crew --skip_provider crewai
```

## Project Structure

- `src/crewai/main.py`: Entry point
- `src/crewai/crew.py`: Crew definition
- `src/crewai/config/`: Agent/task YAML configs
- `src/crewai/tools/`: Custom tools
- `knowledge/`: Knowledge files

## Run

```bash
crewai install
crewai run
```
